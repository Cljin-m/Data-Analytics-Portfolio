# Data Analytics Portfolio

本目录将当前工作区中的 3 个已完成数据分析项目整理为统一作品集。整理方式不是“一个文件夹一个仓库”，而是按能力领域组织代表项目，便于招聘者快速理解项目问题、方法、技术栈和产出。

## 项目模块

| 模块 | 展示重点 | 工具 |
| --- | --- | --- |
| customer-segmentation-rfmi | 用户价值分层、RFM-I 评分、营销标签设计、ROI 情景模拟 | Python, Pandas, NumPy, Matplotlib, Jupyter Notebook |
| conversion-ab-test | 转化页 A/B 测试、实验数据清洗、统计显著性检验、国家维度下钻 | Python, Pandas, SciPy, Statsmodels, Matplotlib, Jupyter Notebook |
| ecommerce-sql-tableau-analysis | 美妆电商用户行为分析、SQL 指标表、转化漏斗、留存、RFM、Tableau 看板 | MySQL, SQL, Tableau, Markdown |

该作品集层只负责整理和说明项目，不改变原始分析逻辑、计算口径或输出结论。

## 数据说明

当前工作区不包含 Notebook 引用的原始 CSV 文件。因此 README 只记录 Notebook 和报告中能够验证的数据路径、字段、方法和输出，不声明仓库已包含完整原始数据。
