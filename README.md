# Data Analytics Portfolio

This repository organizes three completed analytics projects from the current workspace into one recruiter-readable portfolio. The projects cover user segmentation, controlled experiment analysis, SQL-based behavior analysis, and dashboard storytelling.

## Portfolio Modules

| Module | Focus | Tools |
| --- | --- | --- |
| customer-segmentation-rfmi | User value segmentation, RFM-I scoring, marketing tag design, ROI scenario simulation | Python, Pandas, NumPy, Matplotlib, Jupyter Notebook |
| conversion-ab-test | Conversion page A/B test, experiment data cleaning, statistical significance testing, country-level drilldown | Python, Pandas, SciPy, Statsmodels, Matplotlib, Jupyter Notebook |
| ecommerce-sql-tableau-analysis | Beauty e-commerce behavior analysis, SQL metric tables, conversion funnel, retention, RFM, Tableau dashboard | MySQL, SQL, Tableau, Markdown |

## Data Availability

The current workspace does not include the raw CSV files referenced by the notebooks. README files therefore document the file paths, fields, and outputs that are verifiable from the notebooks and reports, but do not claim that the full raw data is packaged in this repository.
